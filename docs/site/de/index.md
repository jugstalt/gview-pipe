# gView.Pipe

gView.Pipe ist eine Workflow-Anwendung: Im Editor verbindest du Nodes, und Items fließen von Node zu Node. Ein Workflow startet nach Zeitplan, über einen Webhook oder von Hand.

## Wo anfangen

- **[Anwenderhandbuch](user-guide/index.md)**: Workflows bauen, ausführen und überwachen.
- **[Administratorhandbuch](admin-guide/index.md)**: gView.Pipe installieren, konfigurieren und betreiben.
- **[Entwicklerhandbuch](developer-guide/index.md)**: eigene Nodes als Plugins schreiben (nur auf Englisch).
