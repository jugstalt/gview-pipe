# gView.Pipe

gView.Pipe is a workflow app: you connect nodes in an editor, and items flow from node to node. A workflow starts on a schedule, through a webhook, or by hand.

## Where to start

- **[User Guide](user-guide/index.md)**: build, run and monitor workflows.
- **[Admin Guide](admin-guide/index.md)**: install, configure and operate gView.Pipe.
- **[Developer Guide](developer-guide/index.md)**: write your own nodes as plugins (English only).
