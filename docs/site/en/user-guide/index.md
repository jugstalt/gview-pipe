# User Guide

This guide is for people who build and run workflows.

- [Getting started](getting-started.md): start the app, open a sample, build a first workflow.
- [The editor](editor.md): palette, canvas, side panel, running and testing, groups.
- [Items and expressions](expressions.md): the data model, `{{ }}` expressions and the Code node.
- [Triggers and webhooks](triggers.md): start workflows from outside and answer the caller.
- [Credentials](credentials.md): store logins and use them in nodes.
- [Error handling](error-handling.md): retries, error outputs and error workflows.
- [Executions](executions.md): what is running, the history and sensitive data.
- [Recipes](recipes.md): the sample workflows, to download.
- [Node reference](nodes/index.md): every node with its parameters (generated, English only).
